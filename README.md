# ShramMitra

ShramMitra is a digital assistance platform designed to help gig workers discover, understand, access and track relevant welfare and social-security benefits.

## Vision

Don't just tell the worker about a benefit.
Guide the worker toward actually accessing it.

## Initial Target Users

- Delivery Partners
- Cab Drivers

## Initial Geographic Scope

- Maharashtra
- Central Government schemes

## Core Journey

Register
→ Login
→ Profile
→ Personalized Benefits
→ Documents
→ Application
→ Tracking
→ Next Action
→ Grievance

## Technology Stack

### Frontend

### Backend
